# Desk Switch 0.4.7

- Fixed Windows audio pacing: real capture packets now determine the sample rate. Enlarged bounded jitter/credit buffers, preserved valid audio across capture gaps, and recovered from brief network stalls without restarting the stream.
- Shared-monitor layout now follows one synchronized checkbox. New profiles leave it off. Each PC shows its own remembered connection instead of one ambiguous pair-wide setup error.
- The destination PC selects its own saved video input first. The active PC provides a fallback for monitors whose inactive port cannot accept DDC/CI. Video must be confirmed before input is forwarded. Monitor-only switching works from either tray after startup on either input.
- Added an explicit input-only setup action for remembering the second PC's connection without moving the keyboard/mouse. Normal F12 and edge switching never silently omit video when a shared monitor is selected.
- Recent bounded service logs travel over the encrypted paired connection. Diagnostics and its copy action include both PCs; the open app retains the last peer report after a disconnect.
- Added **Update both PCs** confirmation. Both verify the same signed release independently. In Windows–Ubuntu pairs, Windows waits for successful Ubuntu package installation. Ubuntu still asks for its local system password; cancelling authorization leaves Windows unchanged. Existing input and the pair stay alive during consent.
- Updated six interface translations and English/Dark screenshots.

Install **v0.4.7 on both PCs**. The coordinated monitor/update messages use **protocol 6**. Other app/protocol versions remain visible in discovery but cannot share devices. Paired updating becomes available after both PCs have this version. Downloads remain **.deb + .exe only**, with signed metadata in the release description.

Validation uses synthetic capture/input/monitor devices, authenticated loopback peers, isolated native UI previews and a private PipeWire server. No physical monitor input or display mode is changed during testing. Monitor firmware, Windows audio hardware and an interactive two-PC installation still require target-machine validation.
