Desk Switch 0.10.0 introduces an animated workspace diagram and a redesigned tray popup for Windows and Ubuntu.

### Improved

- See device hosts, shared sound, display, keyboard, mouse and microphone in one diagram. Direction arrows and moving streams run from a host to its shared devices and onward to receiving computers.
- Click a computer in the diagram to switch. Active input follows the confirmed handoff, and attached hardware remains visible on each computer's card.
- All connected devices stay animated while visible. On Windows, physical key presses highlight the matching keys; mouse movement produces smoothly turning waves with soft transparency, and clicks and scrolling light the mouse controls.
- The microphone's animation forms a vertical column inside its capsule, with clearance from the outline.
- Tray quick controls use the same diagram, direct switching, sharing controls and per-computer volume. Additional source choices and controls remain under **Sharing & volume** in the main window.
- Hidden windows stop rendering; reopening resumes their animations. Temporary input feedback is neither stored nor sent over the network.

### Platforms and upgrade

- This release provides **Windows x86-64** and **Ubuntu 24.04/26.04 x86-64** installers only. No macOS build or update is published because the macOS implementation has not been verified on physical hardware. Earlier macOS releases remain available in the release history.
- Update every Windows and Ubuntu workspace member to **0.10.0** before resuming sharing. The 0.10 and 0.9 release lines do not connect to each other; settings, identities and display arrangements are preserved.
