Desk Switch 0.11.4 brings the Android phone remote to the regular Windows and Ubuntu desktop releases. Use the phone as a touchpad, joystick, or keyboard for the selected computer in your workspace.

### Android phone remote

- Approve the phone once in your workspace. Pointer movement, keyboard input, and cursor preview follow the selected computer during a handoff. A previously unknown computer may require a code check if the phone cannot reach any computer it already knows.
- Keep input flowing while the phone receives cursor preview frames. Motion bursts preserve key and button transitions.
- The phone remote and folder sync use separate ports so both services can run on the same computer.

### Ubuntu

- Choose **Enable native keyboard and mouse** under **Keyboard and mouse permissions** for native input after one administrator approval. Precise screen-edge transitions can still use the Wayland permission dialog.
- Cursor preview resumes when the GNOME companion becomes available. Capture was verified on a private GNOME 50 desktop. If GNOME has yet to load the updated **Desk Switch Tray** extension, sign out and back in.
- Desk Switch waits for Ubuntu's display to wake before changing the monitor input. It retries the wake once if GNOME still reports power saving. The HDMI1 switch on a physical LG monitor after extended idle remains to be verified.

### Updating

Use **Settings → Updates → Check for updates** to install the signed release on Windows x86-64 or Ubuntu 24.04/26.04 x86-64. The update preserves settings, workspace membership, and saved pairings. Android users can update to Desk Switch Remote 0.3.4 via **Controls → Updates**. Update all workspace computers before using workspace pairing. The device and workspace protocols remain 9 and 3.
