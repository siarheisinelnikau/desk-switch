Desk Switch 0.11.3 fixes LG monitor input selection, smooths device activity feedback and bases compatibility on protocol numbers.

### Fixed

- LG 27GK750F uses standard VCP 0x60 input values instead of the incorrect private LG command introduced in 0.11.2. Windows sends one command through the installed NVIDIA driver's direct I²C API; Ubuntu uses standard ddcutil input selection. Existing saved HDMI/DisplayPort ports remain valid.
- Explicitly selecting a computer sends a fresh monitor request even when it is already the logical destination. A stale confirmation after a manual monitor-menu change no longer suppresses the click. Commands still wait for destination preparation and never overlap, retry automatically or read back after selection.
- Microphone and display icon stands remain continuous at small sizes and fractional display scaling, removing the detached dots below the icons.
- Device and workspace protocol numbers determine compatibility. Different application versions, patch distances and release channels no longer prevent sharing when their protocols match. Errors identify the mismatching protocol rather than requiring identical application versions.

### Improved

- Device activity indicators on the workspace diagram appear smoothly and fade out more gently. Renewed activity reverses the transition from its current opacity, including keyboard, mouse and connection feedback.
- Held keys and buttons keep a steady highlight without a running animation clock. Feedback finishes completely when idle and stops while hidden, minimized or reduced motion is enabled.

### Platforms and verification

- Windows x86-64 and Ubuntu 24.04/26.04 x86-64 packages preserve settings, identities and workspace data.
- One physical DP → HDMI1 command was verified on an LG 27GK750F with an RTX 4080: the user confirmed that Ubuntu appeared. The reverse physical transition has not been verified for this release. The LG-specific Windows transport requires a compatible installed NVIDIA driver.
- Protocol compatibility, encrypted input/audio handshakes, fresh monitor requests, fractional-scale icon rasterization, fade reversal and return to idle have regression coverage. Native desktop checks exercise visible, hidden, minimized and restored rendering on isolated Windows and Ubuntu runners.
- Older installed clients can still enforce their former application-version policy until updated. Device protocol remains 9 and workspace protocol remains 3.
