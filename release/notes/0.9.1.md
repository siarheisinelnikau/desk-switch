Desk Switch 0.9.1 fixes mixed-version connections and lets each computer update independently.

- When another computer restarts on a different workspace protocol, Desk Switch checks compatibility before exchanging workspace data. Older computers no longer receive a frame they cannot decode during a remote-first upgrade. The updated computer shows that a compatible version is required.
- Checking, preparing and installing an update on one computer leaves the other computers' update controls available. A compatible remote computer can finish an accepted installation even if the computer that started it restarts.

Desk Switch 0.9.0 and 0.9.1 can share devices during a rolling update. For a workspace still on 0.8.x, upgrade every member before resuming sharing. Existing preferences and trusted computers carry forward.

Downloads are available for Windows x86-64, Ubuntu x86-64, and experimental macOS for Apple Silicon and Intel.
