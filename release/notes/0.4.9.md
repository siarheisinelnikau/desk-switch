Manage either PC from one settings window, update the other computer independently, and reduce audio/cursor interruptions.

## Added
- Per-PC update status and **Update & restart** actions. A PC that is already current can update its partner and stay running.
- Remote theme, language, autostart, automatic connection/update and Windows cursor preferences. Changes are saved on the selected PC.
- Official, unmodified VB-CABLE Windows Pack 46 and macOS Pack 108 archives embedded for offline extraction. Choose the official website or extract into Downloads on either PC; installers are never run automatically. VB-CABLE is donationware by [VB-Audio Software](https://vb-audio.com/Cable/); [support its authors](https://vb-audio.com/Donate/index.htm).

## Improved
- Management stays connected across different app/device-protocol versions, while device sharing waits for matching versions. Each PC verifies its own signed update; remote restart is confirmed from its actual new version.
- Installed Ubuntu packages use narrow password-free actions for input access and newer, pinned-signature Desk Switch updates. Initial package installation still requires normal administrator authorization; Wayland portal consent remains controlled by Ubuntu.
- The Windows fallback cursor follows input events instead of a 16 ms polling timer, coalesces stale positions and reuses its bitmap. Its live on/off setting is available from either PC.
- Short 2 ms transitions soften audio discontinuities at underruns, capture gaps, expired blocks and reconnects; 5 ms ramps smooth volume/mute changes. Windows playback uses MMCSS on its own audio thread. Diagnostics now expose continuity counters.
- Queued pointer motion is combined without losing distance or crossing key/button boundaries. Slow native cursor positioning continues authenticated heartbeats rather than blocking them.

## Fixed
- A shared-monitor action sends at most one input-selection write. Slow or failed readback retries confirmation without writing the port again; idle services no longer poll DDC/CI repeatedly. The active port is used as a fallback only when the destination could not issue a write.
- Linux input-source commands use the known MCCS version directly, avoiding a failing monitor-version probe before VCP 0x60 access.
- Identical peer snapshots no longer keep repainting an unchanged or hidden window.
- Headphone output controls use the actual system level; forwarded audio stays relative to it. Shared-monitor readiness accepts the two ports' different EDID identities.

## Downloads and upgrade
- **Windows x86-64:** desk-switch-v0.4.9-windows-x86-64.exe
- **Ubuntu 24.04/26.04 x86-64:** desk-switch-v0.4.9-linux-x86-64.deb
- **Upgrade from 0.4.8 or older:** install/replace the application once on both PCs. These versions do not support the new asset names or remote management. Settings and pairing are preserved. Later updates can be managed from either PC.
- The release has one title and exactly two installer downloads. GitHub Actions builds, tests, signs with the existing updater identity and verifies the stable publication.

Synthetic input/audio/monitor tests cover the new behavior. Real monitor firmware, Ubuntu desktop authorization and perceived cursor/audio quality still require validation on the target PCs; this release does not claim that every reported disconnect or “out of range” event is eliminated.
