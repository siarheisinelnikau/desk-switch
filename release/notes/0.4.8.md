# Desk Switch 0.4.8

This release fixes shared-monitor readiness and makes headphone volume controls follow the system output.

## Fixed

- **Shared monitor** now uses the checkbox as the declaration that the selected connections share one physical display. Different Windows DisplayPort and Ubuntu HDMI EDID fingerprints no longer block switching or incorrectly request setup on both PCs. Existing saved input codes are retained.
- When switching, the destination application selects its own remembered monitor input. Synthetic round-trip tests require each destination to write its own port; the existing active-port fallback remains available when an inactive DDC/CI connection cannot accept commands.
- The listening PC's audio slider controls the selected output's actual system volume and mute. It adopts the current OS level at startup and follows media-key/OS changes. The other PC's slider applies a relative gain to forwarded audio: a 90% system level and 50% remote level represent a 45% combined level, subject to the system's volume curve.
- Repeated volume changes do not multiply gains. Stopping forwarding or closing Desk Switch preserves the current system volume; per-application recovery data from older releases is restored separately.

## Improved

- Unchanged windows no longer request a repaint every 200 ms. Service events wake the interface, unchanged device scans stay quiet, and timeout/reconnection deadlines remain active.
- The monitor diagram distinguishes a missing local connection, a missing peer connection and duplicate saved inputs.
- Updated all six interface translations and real screenshots. The Windows executable includes the application icon and version metadata.
- The Windows download is now **desk-switch-v0.4.8.exe**. The existing 0.4.7 updater recognizes this versioned name; no filename alias is published. Ubuntu remains the **desk-switch-linux-x86_64.deb** package.

Install **v0.4.8 on both PCs**. Protocol remains **6**; exact application versions must match. Settings, pairing and remembered monitor ports are preserved. This release contains one Windows x86-64 executable and one Ubuntu amd64 Debian package, Stable in-app updates require the signed metadata in the release description.

Validation includes Windows and Ubuntu CI, synthetic audio/input/monitor peers, release/package checks and bounded native UI captures. The optimized Windows fixture produced no new UI frames in six-second visible-idle, hidden and restored-idle samples. Real two-PC audio hardware, monitor firmware and interactive installation still require validation on the target PCs.
