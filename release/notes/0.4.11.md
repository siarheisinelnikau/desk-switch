Quick controls are now available from the tray, and the Windows fallback pointer preserves the system cursor's transparency.

### Added

- Left-click the tray icon to open a compact popup with connection and input status, a PC-switch button, sound/microphone/keyboard/mouse toggles, and per-PC volume and mute controls. The same synchronized settings are used by the full window.
- Windows places the popup near the click within the monitor's work area. Escape or clicking outside dismisses it. The native right-click menu and a shortcut to the full window remain available. Wayland placement is controlled by the compositor.

### Fixed

- Closing the main window with X now hides it in the tray while sharing continues. **Quit application** remains the explicit full exit. When a tray is unavailable, closing still exits safely.
- Removed the magenta transparency key that could leave red or purple cursor fringes. The fallback uses the actual Windows cursor image, native dimensions and hotspot with per-pixel alpha. Legacy background-inverting cursor pixels, including the text cursor, retain their inversion.
- Normal pointer movement reuses the cached image; only background-inverting pixels need a cursor-sized background sample when the pointer moves. No idle animation timer is added.
- Documented the confirmed LG 27GK750F workaround: select DisplayPort once using the monitor's joystick, then resume application switching. The user confirmed that this cleared the recurring **Out of range** message and subsequent switches worked. This documents a hardware workaround; it does not change the monitor protocol.

Install v0.4.11 on both PCs for device sharing. The management channel remains compatible with v0.4.9 and v0.4.10 for coordinated signed updates.

- **Windows x86-64:** desk-switch-v0.4.11-windows-x86-64.exe
- **Ubuntu 24.04/26.04 x86-64:** desk-switch-v0.4.11-linux-x86-64.deb

Validation includes native system-cursor pixel comparisons on light and dark backgrounds, cached-pointer movement, child-popup commands waking the hidden main dispatcher, monitor-work-area placement, authenticated loopback handoffs and native Windows/Ubuntu checks before publication. The dispatch regression was also checked against the old implementation, where it fails.
