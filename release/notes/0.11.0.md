Desk Switch 0.11.0 repairs Ubuntu tray quick controls and prepares the receiving display before switching a shared monitor. It also includes the folder synchronization and resource-sharing work completed since 0.10.0.

### Fixed

- Ubuntu quick controls use retained CPU-rendered native windows, including when the main window is hidden. Opening the device popup no longer creates another OpenGL context.
- The GNOME tray companion routes a completed left-click directly to the device popup and leaves right-clicks to GNOME's native menu. GNOME 50 event actors are handled, and Application settings can check, enable or reload the bundled companion.
- Workspace monitor handoffs wait for the destination to prepare its video output and wake its display before the source sends the saved HDMI/DisplayPort selection. A preparation failure leaves the previous input selected and reports the problem. Input commands remain single-issuance, including after a timeout or restart.
- Windows test executables retain their console subsystem, and accepted resource TCP connections use the correct blocking mode.
- Folder transfers recover across interrupted connections and restarted headless peers, retaining verified partial data and rejecting stale or changed checkpoints.
- Ubuntu background search indexers and thumbnailers cannot start a deferred clipboard-file download before a paste.

### Added

- Explicitly granted, named folder pairs with on-demand synchronization, conflict handling, resumable chunks and recoverable previous versions.
- Authenticated resource catalogs and explicitly granted USB/IP sharing through the external platform backend. Linux can import an allowed shared USB device; Windows USB import is not provided. USB hardware remains unverified.

### Improved

- Workspace route animations finish after a brief transition. Unchanged visible windows settle, and hidden windows stop rendering.
- Automated desktop checks cover Windows, Ubuntu 24.04 and Ubuntu 26.04, including repeated popup opening with the main window visible or hidden.

### Platforms and upgrade

- Install **0.11.0 on every workspace member**. The 0.11 and 0.10 release lines do not connect to each other; existing settings, identities and display arrangements are preserved.
- On Ubuntu GNOME, use **Application → Tray device popup → Enable or reload tray popup** once. The tray menu also offers **Set up left-click popup…**. If GNOME has not discovered the newly installed extension, sign out and sign in once, then enable it here. Extension settings are changed only after this explicit action.
- Installers are provided for **Windows x86-64** and **Ubuntu 24.04/26.04 x86-64**. The Ubuntu package includes the XWayland dependency for reliable tray window hiding and positioning. No macOS installer or update is published.
- Desktop and handoff checks use isolated sessions and simulated monitors. Physical DP/HDMI switching and USB/IP devices were not exercised.
