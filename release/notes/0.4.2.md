- Adds separate **This computer** and **Other computer** volume/mute controls. Levels follow the source PC when the shared speaker or headphones move, and settings synchronize from either PC.
- Controls the listening PC's native application sound separately from received audio. Original application levels are journaled for shutdown and interruption recovery. No virtual audio driver is needed for shared playback.
- Adds independent keyboard, mouse, shared speaker and shared monitor switches. A handoff cannot leave the receiving PC without input; disabling its only shared keyboard/mouse is blocked until control returns.
- Keeps **This computer on the left** in every window while preserving the pair's purple/green identities.
- Shows PC towers around one central shared monitor. Its colour follows the confirmed video input, independently of keyboard/mouse ownership. Unknown inputs stay grey; status reads do not switch video.
- Fixes keyboard/mouse highlighting while input sharing is starting or awaiting access, detects composite relative mice with auxiliary volume axes, and fixes retry after a failed device service.
- Makes `ddcutil`, `pipewire-bin`, `pipewire-pulse` and `pulseaudio-utils` required Debian dependencies. Windows uses its built-in monitor and audio APIs.
- Refreshes the English/Dark screenshots and translations. New settings are available in all six interface languages.

Install **v0.4.2 on both PCs**. This release uses protocol 4 and refuses older protocol/app versions. Downloads remain **.deb + .exe only**; signed update metadata is embedded in the release description.

Validation uses synthetic devices, loopback connections, isolated native GUI previews and Linux/Windows builds. Real two-PC audio latency and monitor firmware behaviour still require hardware validation; DDC/CI remains opt-in.
