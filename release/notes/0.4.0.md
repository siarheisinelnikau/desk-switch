- Replaces separate computer/input/audio setup pages with one **Workspace** showing both PCs and their devices.
- **Available on the network** advertises and discovers together. Incompatible versions/protocols stay visible with an update hint.
- **Link → Accept** exchanges and pins keys automatically. The recipient approves the request; existing pairs reconnect without another prompt. Simultaneous Link requests converge on one connection.
- Both PCs agree on stable **purple/green identities**. Everything stays grey until the routing plan is synchronized. Shared keyboards/mice keep their source colour on the destination and become grey at the source.
- Automatically selects input roles from physical keyboard/mouse presence and rechecks every three seconds. When both PCs have their own input, each controls itself by default. A shared source can be selected on either PC.
- Automatically selects one listening PC, preferring default headphones/Bluetooth. Audio destination, volume, mute, input source and screen-edge layout changes synchronize from either PC.
- Monitor setup remembers **this PC's current connection only** and receives the partner's mapping over the encrypted connection. DDC/CI stays opt-in and requires matching displays and distinct saved inputs. Input switching works without configuring a shared monitor.
- Fixes **X / Quit**: both exit the application even with a working tray. **Minimize to tray** is separate. Unresponsive children cannot block shutdown indefinitely.
- New profiles default to **English + Dark**. Six interface languages remain available. Documentation and regenerated screenshots are English.
- Release downloads are **`.deb` + `.exe` only**. Signed update metadata is embedded in the release description and verified using the pinned Ed25519 key before the shared updater downloads an installer.

Install **0.4.0 on both PCs** (protocol 3). For this first upgrade from 0.3.x or older, install the `.deb` / replace the `.exe` once because older clients expect the separate update-metadata file. Subsequent updates use the new two-file format.

Ubuntu 24.04/26.04 x86-64:

```sh
sudo apt install ./desk-switch-linux-x86_64.deb
```

Validation uses loopback pairing clients, synthetic devices, all six catalogs and isolated native GUI/tray checks, including WM close. Native CI builds/tests Ubuntu and Windows. Real two-PC multicast, interactive Windows, physical input permissions and monitor firmware still need validation on target PCs.
