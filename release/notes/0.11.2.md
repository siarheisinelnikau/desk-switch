Desk Switch 0.11.2 adds native Ubuntu tray clicks that work without an application extension, aligns computer-card buttons, and introduces a model-specific LG monitor input path.

### Fixed

- Ubuntu uses the same native GTK/XEmbed tray path as DownloadManager when the desktop provides it. A single left-click opens device quick controls immediately after installation, including when the main window is hidden. Right-click opens a real native menu. No companion enablement or desktop sign-out is needed for these tray clicks.
- StatusNotifier/AppIndicator remains the fallback for desktops without XEmbed. The bundled GNOME companion remains available for that fallback and for optional Wayland clipboard and screen-edge integration.
- Computer-card Settings and Send files buttons now use the same regular text size and minimum height.
- LG 27GK750F input selection uses the monitor's private VCP 0xF4 command with source address 0x50. Windows uses the installed NVIDIA driver's I2C API; Ubuntu uses ddcutil. Saved HDMI/DisplayPort choices retain their logical values. Unsupported ports or an unavailable NVIDIA binding fail before sending a standard input command.
- Input commands remain single-issuance. The new LG path does not retry a failed command, scan arbitrary monitor registers, or fall back to the standard command after an attempt.

### Platforms and verification

- Windows x86-64 and Ubuntu 24.04/26.04 x86-64 installers are provided. Existing settings, identities and workspace data are preserved. Matching 0.11.2 versions are recommended; 0.11.1 remains compatible.
- The LG model and NVIDIA driver binding were checked read-only on an LG 27GK750F with an RTX 4080. **Physical DP/HDMI switching remains unverified.** Support for this LG-specific Windows path requires a compatible installed NVIDIA driver; other GPU vendors are not covered by this workaround.
- The optional GNOME Wayland companion can still require a new desktop session when first installed. This does not block the native tray popup.
