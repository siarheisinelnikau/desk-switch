- Fixes stale or inconsistent pairing state when a hidden/busy window accumulated updates. State snapshots now coalesce, while connection, approval and disconnect events remain reliable. Delayed results from an older connection attempt cannot overwrite the current attempt.
- Reconnects an existing pair from either PC, adds a cancel action while linking, and clears a device's previous error once that service recovers.
- Adds **Allow keyboard and mouse access** on Ubuntu. The Debian package includes a narrow polkit helper and the required ACL utility. System authentication grants read access only to the selected physical input interfaces; the existing pair is retained and input retries automatically. Replugged interfaces may need approval again.
- Adds **Connect by IP address**, including routed IPv4/IPv6 networks. It uses the same Link/Accept flow and pinned identity checks as discovery, and remains usable when multicast fails. Routing/VPN and firewall access are still required.
- Adds opt-in **Shared microphone**, with a synchronized source choice, forwarded volume and mute. Auto binds to one physical microphone; losing it pauses sharing instead of opening another. Muting stops capture. The microphone uses an independently authenticated transport and does not play to ordinary speakers.
- Ubuntu creates a temporary **Desk Switch microphone** input. A Windows receiver uses an already installed VB-CABLE bridge, with an official setup link when missing; sending a Windows microphone to Ubuntu does not need that driver on Windows.
- Adds synchronized **Settings → Device selection** for both PCs. Linux keyboards/mice and audio endpoints support explicit choices; Windows input remains a keyboard/mouse group. Input reconfiguration is protected while the receiving PC depends on it.
- Adds **Copy diagnostics**, updates all six languages and refreshes English/Dark screenshots.

Install **v0.4.3 on both PCs**. This release uses protocol 5; other app/protocol versions remain visible in discovery but cannot share devices. Downloads remain **.deb + .exe only**, with signed update metadata in the release description.

Validation includes Linux and Windows checks, synthetic device/permission tests, repeated loopback pairing/restarts, isolated GUI/tray tests, and microphone PCM/live-gain/cleanup through a private PipeWire server with a synthetic tone. Physical Windows/VB-CABLE behavior, real two-PC latency and monitor firmware still require target-machine validation. No physical monitor was switched or user microphone/input captured during these checks.
