Desk Switch 0.9.0 adds workspace recovery and improves pairing, transfers, and update preparation.

### Workspaces and privacy

- Remove a computer with the approval of both the previous and remaining voting majorities. Start a new workspace with local preferences if the old majority cannot be recovered.
- Compare the pairing code on both computers. Device details and diagnostics are shared only after confirmation. Expired invitations can be retried.
- Pause microphone forwarding and clipboard synchronization from this computer, even when shared settings are unavailable.
- See connection and device problems next to the affected computer. Copy a diagnostic summary without computer names, addresses, and paths.

### Transfers and updates

- Close transfer progress without cancelling the transfer. Pause, resume, or cancel from Transfers.
- Send up to eight file blocks before waiting for acknowledgements, while retaining verified resume and final checks.
- Prepare and verify updates before restarting the selected computers. Adjacent stable patch versions in the same minor line can share devices when their protocols match.

### Upgrade

Update all members from 0.8.x before resuming sharing. Existing settings and membership carry forward. Native device protocol is **9** and workspace protocol is **3**. Downloads are available for Windows x86-64, Ubuntu x86-64, and experimental macOS on Apple Silicon and Intel.
