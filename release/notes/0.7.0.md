Desk Switch 0.7.0 adds file and folder transfers, automatic coordinator handover in a trusted workspace, and protection against accidental screen-edge switching. It also fixes Ubuntu tray activation and closing the main window to the tray.

### Files and folders

- Send selected files or folders from a computer's card, with progress, cancellation and resumable transfers after a connection interruption.
- With **Shared clipboard** enabled, copy files or folders on one computer and paste them on another after **Copied to clipboard** appears there. Files are staged and verified first; an operating-system paste cannot wait for an unfinished download. **Keep current clipboard** preserves downloads without publishing them, and **Copy received files** can publish completed copies later.
- Card transfers are received under **Downloads / Desk Switch**. Existing files are preserved through collision-safe destination names. Folder contents, relative paths and completed data are validated before they become available.
- Transfers use direct authenticated connections between trusted members, independently of the coordinator. Allow the default **45881/TCP** on **all participating computers** if your private-network firewall requires it; resume and cancellation requests can connect back to the sender.

### Coordinator handover

- Trusted members can elect another coordinator automatically when the current coordinator disconnects, sleeps or restarts. Workspace settings and membership are committed by a majority, preventing two network partitions from independently changing the workspace.
- A three-computer workspace can continue coordinating with two members online. A two-computer workspace needs both members for global changes. A remaining computer retains local access and preferences.
- Returning members catch up with the elected coordinator. Saved identities remain pinned; a new computer still requires explicit approval. An election or reconnection does not replay monitor input-selection commands.

### Screen-edge protection

- A short outward-push delay reduces accidental crossings; moving back cancels the pending crossing.
- Protected corners make it easier to reach controls at the corners of a screen without changing computers.
- Pause automatic edge switching from the application or quick controls. The pause survives reconnection, coordinator changes and restart until you resume it, switch computers manually, or use F11 emergency return. Manual switching and F11 remain available.

### Ubuntu tray and updates

- A left click on the Desk Switch indicator directly opens quick controls. A right click keeps GNOME's native menu. The updated **Desk Switch Tray** companion must be enabled and loaded; after upgrading it, toggle it off and on in **Extensions**, or sign out and back in.
- The main window uses X11/XWayland when available so its close button can hide it in the tray and the popup can be positioned beside the indicator. Keyboard and mouse capture still uses the native Wayland portal when appropriate.
- Update checks now make bounded retries for transient 502, 503, 504 and timeout responses. Rate limits and invalid or incomplete metadata remain errors; pinned signatures, checksums and native installer checks remain required.

### Upgrade

Update **every workspace member to 0.7.0** before resuming sharing. Native device protocol is **9** and workspace protocol is **2**. Settings, identities and display arrangements are preserved.

Mixed versions temporarily disconnect from sharing. If updating other computers remotely from one PC, complete those updates before upgrading that controlling PC; each computer can also update locally.

During the first migration, the **original coordinating computer must run 0.7.0 online once with a trusted quorum** to establish the trusted roster. Afterwards, any surviving majority can coordinate without it.

Downloads include Windows x86-64, Ubuntu x86-64, macOS Apple Silicon and macOS Intel. **macOS functionality remains untested on physical hardware.** Mac bundles are ad-hoc signed and are not notarized; macOS testing and contributions are appreciated.
