Desk Switch 0.11.1 enables the Ubuntu GNOME tray integration automatically when the application starts. There is no separate enablement step in application settings.

### Fixed

- Startup enables only Desk Switch's bundled tray companion, waits for GNOME to finish loading it, and leaves an already working integration alone. Left-click opens device quick controls and right-click keeps the desktop's native menu.
- Removed the unsupported GNOME `ReloadExtension` call, which prevented the previous setup action from enabling the companion.
- Setup runs on a bounded background worker. It does not block the window or keep polling after startup, including while windows are hidden.
- Tray and settings wording now describe integration status and repair rather than requiring manual first-run setup.

### Platforms and upgrade

- Windows x86-64 and Ubuntu 24.04/26.04 x86-64 installers are provided. Existing settings and workspace identities are preserved. Version 0.11.1 remains compatible with 0.11.0.
- GNOME does not discover a new local extension installed into an already running session. A first installation during an existing GNOME session can still require one sign-out/sign-in; Desk Switch enables the companion automatically on the next launch. Previously imported older extension code also needs a new desktop session. Global extension policies remain under desktop control.
