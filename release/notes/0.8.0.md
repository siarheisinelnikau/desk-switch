Desk Switch 0.8.0 adds native file and folder copy/paste between Windows and Linux computers, completes the lazy clipboard transfer lifecycle, and includes reliability and localization fixes across the workspace.

### Native file and folder paste

- Copy files or folders on one computer, open the destination in the other computer's file manager, and paste with the normal system shortcut. The source sends a metadata-only offer first; file contents are read and transferred only after an actual paste request.
- Windows uses Cloud Files placeholders, and Ubuntu GNOME uses the Desk Switch Tray companion with its FUSE file system. Normal copying and pasting on the source computer continues to work while a shared offer waits.
- A compact progress window shows preparation, transfer, verification and confirmed source cleanup separately. Pause, resume and cancel remain available while the main window is in the tray.
- Cut/Move removes originals only after the destination proves a complete committed paste. A changed or unconfirmed source is retained in a recovery folder instead of being deleted.
- Repeated pastes reuse verified content, while the private native cache is removed after the last reader closes. A process restart clears incomplete native paste state without touching user-visible Downloads folders.
- Clipboard offers no longer target offline peers and no longer disable file sharing for the whole workspace. Temporary native clipboard publication failures retry automatically.
- Native file paste into Finder remains unavailable on macOS; explicit **Send files…** and text/image clipboard sharing remain available.

### Workspace, updates and reliability

- The updater rejects signed releases that do not contain the current platform instead of failing with a panic.
- Settings, identity and pending update writes sync the containing directory on Unix and use collision-free temporary files.
- The file-transfer listener no longer falls back to a second address family on an occupied port or shares a Windows service port, preventing split authenticated connections.
- German, French, Spanish and Italian catalogs now cover the remote-management and update surfaces; a regression test rejects long English fallback strings.
- The separate four-computer integration, native clipboard, workspace consensus and file-transfer tests pass locally; the platform CI matrix verifies Ubuntu and Windows before publication.

### Upgrade

Update **every workspace member to 0.8.0** before resuming sharing. Native device protocol is **9** and workspace protocol is **2**; mixed versions wait for a compatible update. Settings, identities and display arrangements are preserved.
