Desk Switch 0.8.1 improves workspace recovery, native file paste, and update reliability.

### Workspace and file sharing

- Restarting a computer restores its last committed workspace membership from disk. Direct file transfers can resume between trusted peers while shared settings wait for a majority.
- Each connection gets the latest peer addresses once its command queue has room. A replacement connection receives its own copy of the address list.
- All TCP listeners follow the same bind policy. A busy port reports the conflict, and systems without IPv6 can still use IPv4.
- Clearing an expired native clipboard offer releases its cache without blocking the next offer. A busy clipboard gets bounded retries, and a newer offer takes priority.

### Settings, diagnostics, and updates

- Settings saves skip occupied temporary filenames and leave the existing files intact.
- The optional diagnostics log writes one record per line in the active profile. A rotation failure keeps new writes within the active log's 2 MiB limit.
- The Windows updater verifies the staged executable again immediately before launch. The Windows download is now named `desk-switch-v0.8.1.exe`.

### Upgrade

Update **every workspace member to 0.8.1** to resume sharing. Native device protocol is **9** and workspace protocol is **2**. Existing settings, trusted identities, and display arrangements carry forward.

Downloads are available for Windows x86-64, Ubuntu x86-64, and experimental macOS Apple Silicon and Intel builds.
