- Saves Ubuntu input permissions for the approved hardware and desktop account. The Debian package restores read access after unplug/replug, port changes and reboot, without another authentication prompt. Serial/unique IDs are used when available; devices without a serial are scoped by model and keyboard/mouse interface. Unrelated devices and other users are not granted access. The GUI still runs as the desktop user; the administrator authorizes the narrow helper once.
- Adds **Settings → Keyboard and mouse permissions → Remember keyboard and mouse access** so an existing temporary grant can be made persistent before unplugging devices. Separate Wayland consent remains controlled by the desktop.
- Shows one common monitor between the two PC towers whenever **Shared monitor** is selected, including before DDC/CI calibration is complete. An unknown video input stays grey and setup is offered beside the diagram. A PC using borrowed input can remember its connection without restarting that input; the new switching mapping is applied only after input returns safely. Readiness to send a monitor command remains independent of the layout; no input codes are guessed or written during setup.
- Adds a temporary, click-through cursor for a receiving Windows PC without a physical mouse when Windows is not drawing its own pointer. It follows cursor position/shape and ends when input is released or a native mouse/cursor returns. It does not change Mouse Keys, ShowCursor counters or registry settings.

Install **v0.4.5 on both PCs**. Protocol remains 5; exact application versions must match. Downloads remain **.deb + .exe only**, with signed update metadata in the release description.

Validation uses synthetic input-permission profiles, hotplug/UID/serial/ownership boundaries, cursor visibility policy, isolated GUI/tray fixtures, native Ubuntu/Windows CI and Debian package checks. No real input permission, monitor setting or system cursor setting was changed during testing. The Windows fallback cursor still needs confirmation on the affected target desktop.
