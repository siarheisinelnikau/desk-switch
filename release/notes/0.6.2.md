Desk Switch 0.6.2 fixes input recovery and physical-device handover, restores shared-headphone indicators, improves GitHub update downloads, and brings back macOS builds. It includes the workspace reconnection fix from 0.6.1.

### Input and device sharing

- A temporary connection loss keeps the last requested computer. After authentication, forwarding resumes there. Control-link reconnection restores that target with a fresh input generation and no automatic monitor writes.
- F11 remains an explicit return to local input. Its cancellation survives reauthentication, worker replacement and a disconnected coordinator, until the controller acknowledges it or the user selects a new target.
- Physically moving keyboards and mice replaces the old host/receiver workers without consuming stale events from the old role. Physical inputs are sampled after slow audio/display scans, and Ubuntu ignores missing or non-character input nodes during unplug/replug races. Explicit device selections remain respected.
- An authenticated recovery clears the current heartbeat error and its matching popup notice. Diagnostic history and unrelated monitor/update errors remain available.
- Explicitly switching to a different PC requests one shared-monitor selection even when an old confirmation claimed it was already selected. Input waits for that result. The existing single-writer, cancellation and no-replay safeguards remain in place.
- Shared headphones appear on participating computer cards in the output PC's colour. Relative mute affects its sender; system mute affects all senders.

### Updates

Transient 502, 503, 504 and timeout failures while opening an installer download get a bounded retry and a fallback to the same repository's official release-asset API. No GitHub account or token is required. Size, SHA-256, pinned signature and native installer verification remain mandatory; corrupt or incomplete payloads are not retried through a different route or installed.

Download/verification failures now have the correct label in all six UI languages, including updates requested from another workspace member.

### macOS downloads

This release includes Windows x86-64, Ubuntu x86-64, macOS Apple Silicon and macOS Intel builds. Mac display geometry, screen-edge routing and exact cursor entry now use the current native protocol. Mac bundles are ad-hoc signed and are not notarized.

**macOS functionality remains untested on physical hardware.** Native compilation, headless tests and package checks do not establish real keyboard/mouse, monitor or audio behavior. macOS contributions and testing are appreciated.

### Upgrade

Update all workspace members to **0.6.2**, with the coordinating computer last. If an older updater cannot download because GitHub returns 504, install this release manually once. Settings, identities and display arrangements are preserved. Device protocol remains **8** and workspace protocol **1**.
