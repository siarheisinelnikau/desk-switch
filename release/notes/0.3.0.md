- Integrates your **rust-auto-updator 0.4.1** core for Windows and installed Debian packages. The host additionally requires the pinned Ed25519-signed manifest to match the exact selected installer URL, version, size and hash. Debian installers now have signed hashes alongside the portable binaries.
- Adds **Light, Dark and System themes**, with immediate switching and saved preferences.
- Adds complete **Russian, English, German, French, Spanish and Italian** interface/tray catalogs (223 translated labels/messages, with preserved placeholders).
- Adds **optional local network discovery**, off by default. Enable it under Computers on both PCs, then choose an IPv4/IPv6 endpoint. Version mismatches are shown. Keys still require direct manual exchange; discovery never pairs or starts services automatically. Manual IP entry remains available.

Ubuntu 24.04/26.04 x86-64: download **desk-switch-linux-x86_64.deb**, then install:

```sh
sudo apt install ./desk-switch-linux-x86_64.deb
```

Open **Desk Switch** from the application menu. This release runs the package-owned executable; future in-app Debian updates use the system password prompt after **Update and restart**. Existing 0.2.x per-user copies keep their signed portable update compatibility; install this `.deb` once to switch to the shared package updater. Windows remains a portable `.exe` with the shared replacement/rollback helper.

Input/audio services stop before installation; cancellation keeps the app open for retry. Pairing, audio settings and startup preferences are preserved. Install **0.3.0 on both PCs** (protocol 2); different application versions are rejected.

Validation includes synthetic tests, all six GUI/tray locales in isolated Xvfb/D-Bus, live theme/language persistence and native CI builds on Ubuntu and Windows. Physical two-PC, interactive Windows and LAN multicast behavior still need validation on target machines. DDC/CI remains opt-in and experimental, including the previously observed LG monitor limitation.
