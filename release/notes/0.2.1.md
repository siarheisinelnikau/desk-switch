Ubuntu now has a real **Debian installer**: download `desk-switch-linux-x86_64.deb`, then run:

```sh
sudo apt install ./desk-switch-linux-x86_64.deb
```

Open **Desk Switch** from the application menu, or run `desk-switch` as your desktop user. The package installs the desktop icon and runtime dependencies. It is built on Ubuntu 24.04 and supports Ubuntu 24.04/26.04 x86-64.

Signed automatic updates continue without sudo through a private per-user application copy. The packaged launcher keeps newer signed updates and refreshes older copies after a package upgrade. Autostart uses the installed launcher with a TryExec guard, so removing the package disables its login entry; pairing/settings stay in the user profile.

Install **0.2.1 on both PCs**; application versions must match exactly (protocol 2). Windows and portable Linux downloads remain available. Tests and release builds run natively on both Windows and Ubuntu. Full physical two-PC behavior still needs validation. DDC/CI switching remains experimental and opt-in, including the previously observed LG monitor limitation.
