Desk Switch Remote 0.3.3 updates the experimental connection and cursor preview.

- The phone remote and folder sync use separate ports. Phones can discover and reconnect to the updated desktop build, and saved PCs keep their pairing.
- Turn **Cursor preview** on or off in the phone's **Controls**. Update the experimental desktop app to use preview without an extra computer setting.

Install the experimental Desk Switch desktop build on each PC that should receive phone input.
