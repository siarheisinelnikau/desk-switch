This is the first Desk Switch Remote release on GitHub. It pairs your Android phone with an experimental Desk Switch desktop build on the same local network.

- Use a touchpad, joystick, or keyboard to control the paired computer. A shared phone can follow the selected computer in your Desk Switch workspace.
- Enable cursor preview on both the phone and computer to see the area around the cursor as you use the remote.
- Open **Controls → Updates** to check for new experimental APKs and install them through Android. Startup checks are enabled by default and can be turned off there.

Download `DeskSwitchRemote-v0.3.2-experimental.apk` for Android 8 or later. Android can update an earlier experimental installation signed with the same certificate in place, preserving settings and pairings.
