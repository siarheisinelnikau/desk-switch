Desk Switch Remote 0.3.4 lets an Android phone control the selected computer in a Desk Switch workspace. Workspace pairing is available with the standard Desk Switch 0.11.4 update on Windows and Ubuntu.

### Workspace and input

- Confirm pairing once to approve the phone in the workspace. Pointer movement, keyboard input, and cursor preview follow the selected computer during a handoff. A previously unknown computer may require a code check if the phone cannot reach any computer it already knows.
- The phone remote and folder sync use separate ports. The input and preview queues keep pointer motion, clicks, and scrolling flowing during active preview.
- Ubuntu supports native keyboard and mouse input after one administrator approval in **Keyboard and mouse permissions**. Precise edge transitions can still use the GNOME permission dialog.

### Cursor preview and display switching

- Enable **Cursor preview** in the phone's **Controls**. On Ubuntu, the app now explains when the GNOME companion is unavailable and resumes preview when capture becomes available. Cursor capture was verified on a private GNOME 50 desktop.
- Desk Switch waits for Ubuntu's display to wake before changing the monitor input. It retries the wake once if GNOME still reports power saving. The HDMI1 switch on a physical LG monitor after extended idle remains to be verified.

### Updating

Use **Settings → Updates** in Desk Switch to update the workspace computers to 0.11.4 before using workspace pairing. If GNOME has yet to load the updated **Desk Switch Tray** extension, sign out and back in.

Download `DeskSwitchRemote-v0.3.4-experimental.apk` for Android 8 or later, or use **Controls → Updates** in an existing signed installation. Android preserves settings and saved pairings when updating an earlier installation signed with the same certificate. The device protocol is 9 and the workspace protocol is 3.
